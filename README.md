# WTE Playbook Hub

Workplace Technology Engineering playbook hub.

Live site: https://jbulos.github.io/wte-playbook-hub/

## Files

- `index.html` — the page GitHub Pages serves
- `wte101-playbook.html` — the Source-ready HTML fragment (same content as the hub, without the page wrapper)

## Edit the page

1. Open [index.html](index.html) on GitHub.
2. Click the pencil (Edit this file).
3. Save the commit. GitHub Pages updates in a few minutes.

Do not commit credentials or private tokens.
